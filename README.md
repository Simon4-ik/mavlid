# 📖 Мавлид ан-Набий — Telegram Mini App eReader & Bot

Замонавий, тезкор ва мобил қурилмаларга тўлиқ мослаштирилган **«Мавлид ан-Набий»** электрон китобхони (Telegram Mini App ва Bot).

---

## ✨ Асосий хусусиятлари

- 📄 **Саҳифама-саҳифа мутолаа**: Китоб сингари қулай, чап ва ўнг томонга варақлаш (swipe ёки тугмалар орқали).
- 🌙 **3 хил ўқиш режими**:
  - **Тунги (Dark OLED)**: кўзни чарчатмайдиган қора ва тилла ранглар.
  - **Сепия (Қоғоз ранги)**: иссиқ китоб қоғози туси.
  - **Кундузги (Light)**: ёруғликда ўқиш учун оқ ва тиниқ фон.
- 🔖 **Хатчўплар (Закладкалар)**: Севимли салавот ёки дуо саҳифаларини 1 та босиш орқали сақлаб қўйиш.
- 📍 **Авто-эслаб қолиш (Zero-Login)**: Ҳеч қандай логин/паролсиз, ҳар бир фойдаланувчи қаерда тўхтаган бўлса, дастур очилганда айнан ўша саҳифа автоматик очилади.
- 🔍 **Юқори сифат (Retina / High-DPI)**: Арабча матнлар ва ҳаракатлар ҳар қандай экранда тиниқ кўринади.
- ⚡ **HTTP Range Byte Streaming**: 8 МБ ли PDF тўлиқ юкланмасдан, керакли саҳифалар бўлакма-бўлак (206 Partial Content) олинади, интернет трафигини тежайди.
- 🤖 **Telegram Bot**: `@mavlidannabiybot` билан бирлашган, `/start` босилганда қулай Mini App тугмасини тақдим этади.

## 🚀 Ишга тушириш

### 1. Локал серверни юритиш:
```powershell
.\.venv\Scripts\python.exe run.py
```
Илова локал тарзда қуйидаги манзилда очилади:
👉 **http://localhost:8080**

### 2. Telegram Mini App (HTTPS) улаш:
Telegram Mini App очилиши учун **HTTPS** ҳавола талаб қилади. Бунинг учун исталган бепул туннелдан фойдаланиш мумкин:

**Вариант 1 (Cloudflare Tunnel — Бепул ва рўйхатдан ўтишсиз):**
```bash
npx cloudflared tunnel --url http://localhost:8080
```

**Вариант 2 (LocalTunnel):**
```bash
npx localtunnel --port 8080
```

**Вариант 3 (ngrok):**
```bash
ngrok http 8080
```

Олинган `https://...` ҳаволани `.env` файлидаги `WEBAPP_URL` га ёзинг:
```ini
WEBAPP_URL=https://sizning-tunnel-manzilingiz.trycloudflare.com
```
Ва серверни қайта ишга туширинг. Бот автоматик тарзда Telegram чатининг пастки қисмида доимий **«📖 Китобни ўқиш»** тугмасини фаоллаштиради!
